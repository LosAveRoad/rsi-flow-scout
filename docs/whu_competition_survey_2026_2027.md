## 四、核心竞争力包装与 3 分钟现场路演脚本

### 4.1 相比传统低代码/工作流工具的差异化优势

| 对比维度 | 传统拖拽式工作流（Dify 等） | 通用开发框架（LangGraph 等） | RSI-Flow Visual Studio（本项目） |
|---|---|---|---|
| **工程对接栈** | 偏重 SaaS 黑盒运维，配置结构不易嵌入已有 Java 工程 | Python 生态主导，前后端联动需要团队自行搭建 Studio | **标准化 `FlowConfig` JSON 协议**直接对齐开源 Java 引擎 `rsi-flow`，前后端结构一致 |
| **建模入口** | 纯手工拖拽配置，新手门槛高 | 纯手写代码建图，结构不直观 | **Vibe Coding 一体化生成**：自然语言描述 → 自动识别模式 → 生成可校验有向图 |
| **结构安全校验** | 多在运行报错后才暴露 | 需要开发者自编校验钩子 | 画布内置 **`validateFlowGraph` 实时静态校验**：阻断悬空节点、孤立连线及无保护循环边 |
| **组件复用形态** | 整套平台绑定，难以抽取为轻量 NPM 组件库 | 无开箱即用独立画布组件 | 拆分为独立可复用库 `rsi-flow-react`（`@xyflow/react` v12）+ 工作室 `rsi-flow-visual` |

## 五、立项申报书简介模板与风险防控清单

### 5.1 申报书核心简介（约 400 字可直接复用模板）

> 本项目面向智能体与软件工程融合时代下的工作流编排需求，依托开源 `rsi-flow` 工作流生态，研发了基于 `@xyflow/react` v12 的轻量化前端画布组件库 **`rsi-flow-react`** 与 Vibe Coding 可视化流程工作室 **`rsi-flow-visual`**，并构建了面向高校学科竞赛调研决策的示范工作流 **`FLOW_WHU_COMPETITION_SCOUT`**。系统创新性地打通了“自然语言需求输入 → 领域模式识别 → 有向无环图（DAG）分层自动布局 → 结构静态安全校验 → 双向标准 `FlowConfig` JSON 导出”的全链路闭环，使研发人员无需编写繁琐底层配置，即可在数分钟内完成含顺序节点、嵌套子流程与 JEXL 条件分支在内的复杂业务流建模与主路径执行仿真。目前项目已在 GitHub 全量开源，配套 Vitest 自动化测试套件与 GitHub Actions 持续集成流水线，核心成果计划同步应用于中国软件杯、CCF 开源创新大赛、中国高校计算机大赛（C4）及“挑战杯”全国大学生课外学术科技作品竞赛等多项国家级赛事中，形成“技术验证—开源沉淀—以赛促研”的良性循环。
